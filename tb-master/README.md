# TB Master

Отдельный мобильный тренажёр по ТБ внутри репозитория `test-otvt`. Существующий сайт и его файлы не заменяются.

## Что есть
- Режим обучения и режим экзамена.
- Выбор направления: БиОТ, пожарная, электрическая и промышленная безопасность.
- Случайная выборка вопросов, таймер, результат, список ошибок.
- Локальная история на устройстве.
- Регистрация и вход через Cloudflare Pages Functions.
- Хранение учётных записей и истории попыток в Cloudflare D1.
- Пароли хранятся не в открытом виде: PBKDF2-SHA-256 с уникальной солью.
- Сессионный токен — подписанный HMAC, в HttpOnly/Secure/SameSite cookie.

## Важно о базе вопросов
Тренажёр читает исходную базу из `../poisk_pravilnyh_otvetov-1.html` (319 вопросов) и не дублирует её. Поэтому при публикации Cloudflare Pages нужно публиковать **корень репозитория**, а не только папку `tb-master`. Страница будет доступна по адресу `/tb-master/`.

## Развёртывание на Cloudflare Pages
1. В Cloudflare Dashboard откройте Workers & Pages и создайте новый Pages project из GitHub-репозитория `guldanaerzhigit-lgtm/test-otvt`.
2. Для сборки укажите команду сборки пустой (или `exit 0`, если интерфейс требует команду), build output directory: `.` (корень репозитория). Не задавайте root directory `tb-master`, иначе исходный файл с базой вопросов не попадёт в публикацию.
3. В настройках Pages project → Settings → Functions → D1 database bindings добавьте binding:
   - Variable name: `DB`
   - D1 database: выберите созданную базу для TB Master.
4. В Workers & Pages → D1 создайте базу, например `tb-master-db`.
5. Откройте D1 → Console и выполните содержимое файла `tb-master/schema.sql`.
6. В Pages project → Settings → Variables and Secrets добавьте секрет `JWT_SECRET`. Используйте длинный случайный ключ (минимум 32 случайных байта). Не помещайте его в код, HTML или публичный репозиторий.
7. После добавления binding и секрета запустите новый deployment.
8. Откройте `https://ВАШ-ПРОЕКТ.pages.dev/tb-master/`, создайте аккаунт и проверьте, что после теста попытка появилась в истории.

## Примечания
- Если D1/секрет ещё не настроены, тестирование и история на этом устройстве работают локально, но вход и синхронизация не заработают до настройки API.
- В Cloudflare Pages Functions должны публиковаться файлы из корневой папки `functions/api/`.
- Не переиспользуйте пароль от других сервисов.
- Вопросы и ключи ответов взяты из пользовательских исходных материалов; правильность и актуальность нормативных ответов не подтверждалась юридической экспертизой. Для официальной аттестации сверяйтесь с актуальными нормативными актами и утверждённым работодателем тестом.
